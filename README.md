## ReverseLab

Curious how things work – and how to make them work better.
I take technology apart, try out new tools and AI, and build small open-source apps that solve one problem well.

### Projects

| | |
|---|---|
| **[MediaTidy](https://github.com/Jo-ReverseLab/media-tidy-mac)** | macOS app for photographers: back up, find duplicates and sort photos and videos by date, camera and lens. Safe by default – every run starts as a dry run and can be undone. [Download](https://github.com/Jo-ReverseLab/media-tidy-mac/releases/latest) |
| **[lr2lc](https://github.com/Jo-ReverseLab/lr-classic-to-lightcraft)** | Moves an Adobe Lightroom Classic catalog into [LightCraft](https://github.com/storytold/lightcraft): keywords, albums, ratings and edits. Reads the catalog read-only, starts with a dry run and can be run again without duplicates. Desktop window and command line. [Quick start](https://github.com/Jo-ReverseLab/lr-classic-to-lightcraft#quick-start) |
